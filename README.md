# ✨ css-fx

> Zero-config CSS effects library — hover animations, glassmorphism, neon glow, flip cards, gradient borders, micro-interactions, and scroll reveals.

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![GitHub release](https://img.shields.io/github/v/release/hojullc/css-fx)](https://github.com/hojullc/css-fx/releases)

## Features

- **Just add a class** — no JavaScript required for most effects
- **50+ effects** across 8 categories
- **CSS custom properties** for easy theming
- **Reduced-motion safe** — all animations pause with `prefers-reduced-motion`
- **Tiny** — 4 KB gzipped, zero dependencies

## Install

**CDN**
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/hojullc/css-fx@1/src/css-fx.css">
```

**npm**
```bash
npm install css-fx
```

## Quick start

```html
<link rel="stylesheet" href="css-fx.css">

1<div class="fx-lift">Hover me</div>

<div class="fx-glass" style="padding:24px">Glass card</div>

```
